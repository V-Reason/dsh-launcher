# vdsh 文档目录

面向后续迭代开发的详细文档。入门/日常用法见根目录 `README.md` 的「快速开始」。

| 文档 | 内容 | 建议阅读时机 |
|---|---|---|
| [usage.md](usage.md) | 完整使用参考：命令行、vdsh.yaml 全部键、手机访问、工作区、数据同步、环境变量 | 配置或使用遇到疑问时 |
| [design.md](design.md) | 定位与架构设计：分层、功能协议、关键机制（配置/环境桥/动画/启动状态机）与其理由 | 接手开发、改架构前 |
| [dev.md](dev.md) | 开发指南：目录职责、新增功能 5 步、编码约定、核心机制调用、测试与发布 | 开始写代码前 |
| [experience.md](experience.md) | 经验与踩坑记录：PS 5.1 差异、编码、YAML、沙箱限制、动画并发等 | 复现/排查问题时 |

阅读顺序建议：

- 日常使用者：`README.md`（快速开始）→ `usage.md`（按需查阅）。
- 新开发者：`README.md` → `design.md` → `dev.md`；遇到诡异现象先扫一遍 `experience.md`。
- 调试者：`experience.md`（按标题检索）→ `dev.md` 的「测试方法」。
